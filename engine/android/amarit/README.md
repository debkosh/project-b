# amarit's update notification

`UpdateNotification.java` and `res/values/amarit_notification.xml` are amarit's
(github.com/sudiptadeb/amarit, `android/amarit/src/main`, v0.10.4), taken as they are: the
system's notification for the Go updater's state ([docs/updates.md](../../../docs/updates.md)).
amarit ships them as plain sources for builds without Gradle, as this one is. Take a newer
version from the same place; change the words in the XML, not the Java.
