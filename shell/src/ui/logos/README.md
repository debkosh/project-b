# Browser logos

The logos Import shows beside each browser (`BrowserIcon.vue`), one file per browser named by
browserdata's id for it. A browser with no file of its own shows its family's: `chrome-beta`
shows `chrome`'s. A logo is its owner's trademark, shown only to name the browser.
